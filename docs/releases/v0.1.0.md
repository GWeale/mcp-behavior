# MCP Behavior 0.1.0

MCP Behavior 0.1.0 is the first public alpha. It runs strict YAML scenarios against an MCP server and checks returned values plus declared file, tree, SQLite, or custom-probe effects.

The release includes expectation tests, reviewed JSON baselines, and live candidate-versus-reference comparison. Stdio and Streamable HTTP targets use the official MCP Python SDK. Reports are available for terminals, JSON consumers, pull request comments, and JUnit readers.

Five runnable suites show direct expectations, a recorded baseline, schema-compatible business-value drift, a successful tool response with the wrong file effect, and explicit normalization followed by an inconclusive abrupt server exit. The clean-wheel release gate executes each suite with its documented exit code.

## Compatibility

- Python 3.11 through 3.14 are tested on Linux, macOS, and Windows.
- Contract schema: 1
- Evidence schema: 1
- Baseline schema: 1
- MCP protocol client modes: auto, 2026-07-28 modern, and SDK legacy

## Security boundary

Servers and configured commands run as trusted code. The release bounds output and process lifetime, contains relative observer paths, opens SQLite read-only, rejects credential-bearing target URLs, avoids HTTP redirects, and sanitizes request and response evidence before persistence. These controls do not isolate hostile code.

## Artifacts

The release contains a wheel, source archive, and `SHA256SUMS`. The release workflow builds them from the tagged commit and publishes the wheel and source archive to PyPI through trusted publishing.
